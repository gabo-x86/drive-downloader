# Drive Downloader

Chrome extension that captures the video playback responses generated by Google Drive (requests to `workspacevideo-pa*`) and lets you download the video at any of the available qualities directly from the extension popup.

## What it does

When you open a video in Google Drive, the Drive page makes a request to the video playback service. That response contains the full list of encoded versions of the video (each with its resolution and size). The extension intercepts that response, extracts the list of qualities, and exposes them in its popup.

For each quality it shows:

```
<video title> • <resolution>p • <size in bytes>
```

Example:

```
DP164PD.mkv • 360p • 3.0 MB
DP164PD.mkv • 720p • 3.0 MB
DP164PD.mkv • 1080p • 3.0 MB
```

Clicking a row downloads the video at that quality.

## How it works

The extension uses three cooperating pieces.

1. Interception
   The extension injects a script into the Google Drive page that patches the page's own `fetch` and `XMLHttpRequest`. Only requests whose URL starts with `https://workspacevideo-pa` are inspected. The response is cloned (so the video player keeps working normally), parsed, and the title plus the `progressiveTranscodes` array are extracted.

2. Bridging
   The page context cannot talk to the extension directly, so the captured data is posted to the extension's content script via `window.postMessage`, which forwards it to the background service worker.

3. Storage and UI
   The background service worker accumulates the captured videos in `chrome.storage.local`. The popup reads that storage, renders one clickable row per quality, and triggers the download through the Chrome downloads API.
